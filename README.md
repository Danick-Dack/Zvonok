# Звонок — расписание лицея №165

Сколько до звонка, какой следующий урок и в каком он кабинете. Для всех 19 классов лицея (7А–11Г).

- **Сайт** (`site/`): живой таймер, расписание любого класса, неделя целиком, поиск кабинета и свободных кабинетов,
  конструктор своего расписания и оформления, установка для Android и iPhone, QR-код и плакат для класса.
  Один файл без внешних запросов: открывается даже без интернета и даже как файл из Telegram.
- **Android** (`app/`): чёрное несмахиваемое уведомление с живым таймером, виджеты 2×2 и 2×1, своё расписание,
  темы для виджетов и уведомления, режим каникул, отправка APK другу без интернета, проверка обновлений.
- **iPhone**: сайт ставится «как приложение» (Safari → «На экран „Домой“»), а виджеты для экрана блокировки
  делает скрипт `ios/Uroki7B.js` для бесплатного **Scriptable**. Сайт сам собирает этот скрипт под любой класс.

## Данные

Всё расписание и звонки — в одном файле `data/schedule.json`. Его используют и приложение (как asset), и сайт.
Коды предметов расшифровываются в `subjects`, кабинет `с/з` — спортзал.

## Батарея

- Все будильники «не будящие» (RTC): спящий телефон приложение не будит никогда.
- Пока экран выключен, поминутных обновлений нет, только смена состояния на звонках.
- При включении экрана служба сразу обновляет уведомление и виджеты.
- Таймеры (Chronometer) тикают сами; «экономный таймер» убирает и секунды.
- «Каникулы» выключают всё: ни службы, ни будильников.

## Безопасность и приватность

- В сеть приложение выходит только с разрешения пользователя (спрашивает один раз, по умолчанию выключено): раз в сутки, когда открыто, узнаёт у GitHub номер последнего релиза (`Updates.java`). Только HTTPS (`usesCleartextTraffic=false`).
- Резервное копирование и перенос данных выключены (`allowBackup=false`, `data_extraction_rules.xml`).
- Внутренние сигналы (`TickReceiver`) не экспортированы; наружу открыт только приёмник системных событий.
- `ApkProvider` отдаёт только собственный APK, только для чтения и только по явному «Поделиться».
- Коды расписания и темы проверяются и обрезаются при импорте.
- Сайт: строгий CSP, никаких внешних скриптов, шрифтов и счётчиков; всё хранится в `localStorage` браузера.

## Несмахиваемое уведомление

Уведомление держит служба переднего плана (`LessonService`): «Очистить всё» его не убирает.
На Android 14+ система разрешает смахивать даже такие уведомления, поэтому приложение сразу показывает его снова.

## Сборка

- **APK:** GitHub Actions (`.github/workflows/build.yml`) при каждом пуше. В **Releases** появляются
  `Zvonok-165.apk` и `Zvonok-165.html` (сайт одним файлом).
  Постоянный ключ подписи берётся из секретов `SIGNING_KEY_B64` (keystore в base64) и `KEYSTORE_PASSWORD`:
  с ним обновления ставятся поверх. Без секретов APK подписывается debug-ключом.
- **Сайт:** `python tools/build_site.py` (нужны `qrcode` и `pillow`) собирает `site/` из `site/src/`,
  `data/schedule.json` и `ios/Uroki7B.js`. Публикация — `.github/workflows/pages.yml` на GitHub Pages
  (работает, когда репозиторий публичный).
