# Уроки 7Б

Android-приложение с расписанием 7Б: одно тихое уведомление на экране блокировки, которое обновляется каждую минуту, и чёрный минималистичный виджет.

## Что показывает

- **На уроке:** предмет, «урок 3 / 7», сколько осталось, во сколько звонок на перемену, следующий урок и кабинет.
- **На перемене:** сколько осталось, во сколько звонок на урок, следующий урок и кабинет.
- **За час до уроков:** сколько до первого звонка и первый урок.
- После уроков уведомление исчезает, виджет показывает завтрашний день.

## Сборка

APK собирает GitHub Actions при каждом пуше (`.github/workflows/build.yml`).
Готовый файл `Uroki7B.apk` появляется в разделе **Releases** репозитория.

## Поменять расписание

Всё расписание и время звонков лежат в одном файле:
`app/src/main/java/app/urok7b/Schedule.java` (массивы `BELLS` и `WEEK`).
