# Уроки 7Б

Android-приложение с расписанием 7Б: чёрное несмахиваемое уведомление на экране блокировки с живым таймером до звонка и чёрные минималистичные виджеты 2×2 и 2×1.

## Что показывает

- **На уроке:** предмет и кабинет, «урок 3 / 7», живой таймер до звонка, прогресс урока, во сколько звонок и во сколько домой, следующий урок и его кабинет.
- **На перемене:** таймер до звонка на урок, следующий урок и кабинет.
- **За час до уроков:** таймер до первого звонка и первый урок.
- **После уроков и в выходные:** когда начинается следующий учебный день, сколько в нём уроков и с чего он начинается.

## Батарея

- Все будильники «не будящие» (RTC): спящий телефон приложение не будит никогда.
- Пока экран выключен, поминутных обновлений нет, только смена состояния на звонках.
- При включении экрана служба сразу обновляет уведомление и виджеты.
- Таймеры (Chronometer) тикают сами, без участия приложения.

## Несмахиваемое уведомление

Уведомление держит служба переднего плана (`LessonService`): «Очистить всё» его не убирает, смахнуть его нельзя.
На Android 14+ система разрешает смахивать даже такие уведомления, поэтому приложение сразу показывает его снова (`deleteIntent` → `TickReceiver`).

## Сборка

APK собирает GitHub Actions при каждом пуше (`.github/workflows/build.yml`).
Готовый файл `Uroki7B.apk` появляется в разделе **Releases**.
Постоянный ключ подписи берётся из секретов репозитория `SIGNING_KEY_B64` (keystore в base64) и `KEYSTORE_PASSWORD`. С ним новые версии ставятся поверх старых. Без секретов APK подписывается debug-ключом.

## Поменять расписание

Всё расписание и время звонков лежат в одном файле:
`app/src/main/java/app/urok7b/Schedule.java` (массивы `BELLS` и `WEEK`).

## iPhone

Версия для iPhone — скрипт `ios/Uroki7B.js` для бесплатного приложения **Scriptable** из App Store (нужен iOS 16 или новее).
Даёт виджеты на экран блокировки (прямоугольный, круглый, строка над часами) и на рабочий стол (маленький, средний, большой),
плюс экран с расписанием внутри Scriptable. Скрипт запускается только в момент звонка, таймер тикает силами iOS.
