# Звонок. Расписание лицея №165

Сколько до звонка, какой следующий урок и в каком он кабинете. Для всех 19 классов лицея (7А–11Г).

**Открыть:** [danick-dack.github.io/Zvonok](https://danick-dack.github.io/Zvonok) ·
[о проекте](https://danick-dack.github.io/Zvonok/about.html) ·
[приложение для Android](https://github.com/Danick-Dack/Zvonok/releases/latest)

## Что умеет

- **Сайт:** живой таймер до звонка, расписание любого класса, неделя целиком, поиск кабинета и свободных кабинетов,
  своё расписание и оформление, QR-код и плакат для класса. Работает без интернета и ставится как приложение.
- **Android:** несмахиваемое уведомление с таймером, виджеты 2×2 и 2×1, большой таймер на экране блокировки,
  своё расписание, темы, режим каникул, отправка приложения другу без интернета.
- **iPhone:** сайт ставится на экран «Домой» (Safari → «Поделиться» → «На экран „Домой“»), а виджеты
  для экрана блокировки работают через бесплатное приложение **Scriptable**. Скрипт под свой класс выдаёт сам сайт.
- Замены, сокращённые дни и каникулы учитываются везде одинаково.

## Приватность

- Без регистрации, рекламы, счётчиков и внешних скриптов. Выбранный класс и настройки хранятся только на твоём устройстве.
- Приложение Android выходит в интернет, только если ты сам это разрешил, и только по HTTPS:
  узнать о новой версии и скачать свежие замены.
- Обновления виджета iPhone проверяются по цифровой подписи: чужой или повреждённый файл не установится.
- Форма обратной связи отправляет письмо через сервис Web3Forms. Больше никуда ничего не уходит.

## Батарея

- Спящий телефон приложение не будит, пока экран выключен, поминутных обновлений нет.
- Сайт во время урока перерисовывается раз в секунду и только то, что видно; в фоне не работает.
- Режим «Каникулы» выключает всё.

## Устройство

| Папка | Что там |
|---|---|
| `data/` | расписание, звонки, каникулы и замены (один источник для всех платформ) |
| `site/src/` | исходники сайта, `site/` собранный сайт |
| `app/` | приложение Android |
| `ios/` | скрипт виджетов для Scriptable |
| `tools/` | сборка сайта, проверка данных, автотесты |
