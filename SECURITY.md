# Безопасность

Если нашёл уязвимость (например, способ подсунуть виджетам iPhone чужое обновление, выполнить чужой код
на сайте или получить доступ к чьим-то данным), не публикуй детали в открытом Issue.

Напиши на почту проекта **zvonok165lyceumalmaty@gmail.com** или через [форму на сайте](https://danick-dack.github.io/Zvonok/feedback.html)
(тип «Ошибка», без подробностей, мы сами свяжемся). Опиши, что нашёл и как это повторить.
Ответим в течение недели и скажем, когда исправим.

## Что уже защищено

- Сайт: строгая политика CSP по хешам, без внешних скриптов и трекеров.
- Виджеты и приложение на iPhone ставят новую версию, только если она подписана ключом «Звонка» (Ed25519).
  Закрытого ключа в репозитории нет, он хранится в секретах GitHub Actions.
- Приложение Android подписано постоянным ключом, ходит в интернет только по HTTPS и только если пользователь разрешил.
- Контрольная сумма SHA-256 каждого APK есть в описании релиза.

## Какие версии поддерживаются

Исправления выходят только для последней версии. Официальные сборки только в
[Releases](https://github.com/Danick-Dack/Zvonok/releases) этого репозитория и на сайте danick-dack.github.io/Zvonok.
