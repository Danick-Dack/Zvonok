# Правила общения

«Звонок» делают ученики для учеников. Чтобы всем было нормально:

- Общаемся вежливо, без оскорблений, травли и переходов на личности.
- Критикуем код и идеи, а не людей.
- Не публикуем чужие личные данные: фамилии, телефоны, переписки, фото.
- Учителей и одноклассников не обсуждаем: проект про расписание, а не про людей.
