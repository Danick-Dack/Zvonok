# Как помочь «Звонку»

Проект открытый (лицензия MIT): код можно смотреть, копировать, менять и выкладывать свои версии.
Если делаешь свою версию для другой школы, назови её иначе, чтобы её не путали с этим «Звонком».

## Нашёл ошибку или есть идея

- Ошибка в расписании, баг или идея: открой [Issue](https://github.com/Danick-Dack/Zvonok/issues/new/choose),
  там есть готовые формы. Можно и без аккаунта: [форма на сайте](https://danick-dack.github.io/Zvonok/feedback.html).
- Уязвимость: не пиши о ней в открытом Issue, смотри [SECURITY.md](SECURITY.md).

## Как всё устроено

| Папка | Что там |
|---|---|
| `data/` | расписание, звонки, каникулы (`schedule.json`), замены (`changes.json`), «Что нового» (`changelog.json`). Один источник для всех платформ |
| `site/src/` | исходники сайта: страницы, `css/`, `js/`. Собранный сайт лежит в `site/`, его руками не правят |
| `site/src/js/rules.js` | правила дня: каникулы, замены, сокращённые звонки, что идёт сейчас. Общие для сайта и iPhone |
| `app/` | приложение Android на Java, без сторонних библиотек |
| `ios/Zvonok.js` | скрипт для Scriptable: виджеты iPhone и приложение «Звонок» |
| `tools/` | сборка сайта, проверка данных, автотесты |

Android считает день на Java (`Schedule.java`), но ответы обязаны совпадать с `rules.js`:
`tools/golden.py` снимает эталон с `rules.js`, юнит-тесты Android сверяются с ним.

## Как запустить у себя

Нужны Python 3 и Chrome. Для сборки сайта: `pip install qrcode pillow`.

```
py tools/build_site.py      # собрать сайт в site/
py tools/check_data.py      # проверить расписание и замены
py tools/test_site.py       # автотесты сайта и скрипта iPhone в безголовом Chrome
py tools/golden.py --check  # эталон Android совпадает с rules.js
py tools/preview_iphone.py  # снимки виджетов и приложения iPhone в .tmp/team/
```

Приложение Android собирает GitHub Actions (`.github/workflows/build.yml`): там же юнит-тесты, lint и снимки
экранов на эмуляторе. Локально подойдёт Android Studio или `gradle assembleDebug` (Gradle 8.7 и JDK 17, как в CI).

## Правила изменений

- Поменял `rules.js`: запусти `py tools/golden.py`, чтобы обновить эталон Android, и поправь `Schedule.java`, если тесты упали.
- Тексты для людей: простой русский, без длинных тире. В `changelog.json` у записи до 4 пунктов, записи от новых к старым.
- Батарея важнее всего: ни одна функция не будит спящий телефон и не обновляет экран чаще, чем меняется то, что на нём видно.
- Никаких трекеров, рекламы и сторонних скриптов. Данные пользователя остаются у него на устройстве.
- Данных об учителях в проекте нет и не будет.
- Ключи подписи никогда не кладут в репозиторий. Сборка без ключа просто выходит без подписи.

## Расписание и замены

Расписание четверти лежит в `data/schedule.json`, замены на конкретные дни в `data/changes.json`
(формат описан прямо в файле). После правки: `py tools/check_data.py` и `py tools/build_site.py`.
Изменения расписания проверяет автор проекта: присылай их через Issue «Ошибка в расписании» или Pull Request.

## Pull Request

1. Сделай форк и ветку.
2. Проверь: `check_data`, `test_site`, `golden.py --check` зелёные.
3. Опиши, что и зачем поменял. Если поменялся вид, приложи снимок экрана.
