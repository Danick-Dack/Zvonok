# Свои иконки «Звонка»

Сюда кладутся нарисованные иконки: квадратный PNG от 512×512, без прозрачности, знак в центре (края на телефоне скругляются).
Имя файла станет подписью под иконкой, например `Космос.png`.

- **Сайт и iPhone.** Больше ничего делать не надо: сборка (`python tools/build_site.py`) сама добавит картинку
  в «Ещё» → «Оформление» → «Иконка».
- **Android.** Положи тот же PNG в `app/src/main/res/mipmap-xxxhdpi/` под латинским именем (например `ic_alt_space.png`)
  и добавь в `app/src/main/AndroidManifest.xml` ещё один блок `<activity-alias>` по образцу соседних: имя `.IconSpace`,
  `android:icon` и `android:roundIcon` со значением `@mipmap/ic_alt_space`, подпись в `icon_name`. Приложение само покажет её в «Ещё» → «Оформление» → «Иконка приложения».
